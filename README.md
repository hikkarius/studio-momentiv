# Студія моментів

Локальна веб-студія, яка знаходить найвірусніші моменти в довгих відео (подкасти, інтерв'ю, стріми, лекції — від 10 хвилин до кількох годин) і віддає готові кліпи **15–60 секунд** для Shorts / Reels / TikTok.

Як це працює:

1. Відео з YouTube/TikTok-посилання (через `yt-dlp`) або з файлу. Можна додати одразу кілька: вони стають у **чергу** й обробляються по одному.
2. Faster-Whisper розпізнає мову **локально** (на відеокарті NVIDIA, якщо є, інакше на процесорі). Транскрипція кешується в `.transcript_cache/`, тому повторний аналіз того самого відео миттєвий.
   Мову відео обирають на головній («Змінити» → «Мова відео»): українська, англійська, польська, німецька, французька, іспанська, італійська, португальська або «Автоматично» (Whisper вгадує мову за першими ~30 с мовлення; так працюють і інші мови). Мова за замовчуванням задається в «Налаштуваннях». Якщо змінити мову для вже розпізнаного відео, воно розпізнається заново.
3. Google Gemini читає транскрипцію з таймкодами й обирає найсильніші, самодостатні моменти: заголовок, хук, опис, хештеги, вірусний бал. Заголовок, опис і хештеги пишуться мовою відео (вони для публікації), а пояснення «чому це вірально» — українською.
4. У студії можна переглянути кожен момент у плеєрі, скачати кліп MP4 (без втрати якості), субтитри SRT, `metadata.txt` / `metadata.json`.

Якщо Gemini недоступний, студія **чесно показує помилку** і не вигадує кліпів (див. нижче).

## Просто встановити (для друзів)

1. Відкрий [останній реліз](https://github.com/hikkarius/studio-momentiv/releases/latest) і скачай **Studio-Momentiv.zip**.
2. Розпакуй архів у просту папку, наприклад `C:\StudioMomentiv` (не в OneDrive і не на робочий стіл).
3. Двічі клікни **«Встановити»**. Якщо Windows покаже «Windows захистила ваш ПК», натисни «Докладніше» → «Усе одно запустити». Чекай 10–20 хвилин, поки все скачається.
4. Запускай студію ярликом **«Студія моментів»** на робочому столі. При першому запуску студія попросить безкоштовний ключ Gemini і покаже, як його отримати.

Нові версії ставляться кнопкою **«⬆ Оновити»** вгорі студії, коли вона з'являється. Твої відео, ключ і налаштування при оновленні лишаються.

Розробка (запуск з коду, тести) описана нижче.

## Що потрібно

- **Windows 10/11**
- **Python 3.12**
- **ffmpeg** і **ffprobe** у `PATH` (наприклад, `winget install Gyan.FFmpeg`). Студія сама підхопить ffmpeg, встановлений через winget, навіть без перезапуску терміналу.
- **Відеокарта NVIDIA** — опційно, але бажано: транскрипція на GPU в рази швидша. Потрібні лише драйвери; CUDA-бібліотеки (`cublas`, `cudnn`) ставляться через `pip` разом із залежностями.
- **Ключ Gemini API** — безкоштовно на [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey). Безкоштовний рівень іноді відповідає `503 / high demand` — тоді просто повторіть аналіз за кілька хвилин.

## Перше встановлення

У папці проєкту (зараз це `C:\studio_momentiv`) виконайте в PowerShell:

```bash
python -m venv .venv
```

```bash
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

```bash
copy .env.example .env
```

Відкрийте `.env` у блокноті й впишіть свій ключ (або пізніше вставте його в студії: «⚙ Налаштування» → «Розпізнавання й ШІ» → «Зберегти ключ»):

```env
GEMINI_API_KEY=ваш_ключ_gemini
```

> `.env` не потрапляє в git (він у `.gitignore`) — ключ залишається тільки на вашому комп'ютері.

## Щоденний запуск

Подвійний клік по **`Запустити_Студію.bat`** (або скопіюйте `run_studio.example.bat` → `run_studio.bat` і запускайте його).
Браузер сам відкриє **http://127.0.0.1:8000**. Щоб зупинити студію — закрийте чорне вікно консолі.

Без `.bat`:

```bash
.venv\Scripts\python.exe run_studio.py
```

> Усі `*.bat`, крім `run_studio.example.bat`, ігноруються git'ом — туди можна вписувати особисті налаштування.

## Як користуватись

1. На головній вставте **одне або кілька посилань** на YouTube чи TikTok (вкладка «Посилання») і натисніть **«В чергу →»**. Або оберіть / перетягніть один чи кілька файлів MP4, MOV, MKV.
2. Перед цим можна вибрати **кількість кліпів** («Авто» — приблизно 1 на кожні 25 секунд відео, або 5–100) і **що шукати**:
   - 🔥 Вірусні гачки — сильні хуки, емоції, несподіванки;
   - 💡 Експертні поради — корисні поради;
   - 🎭 Емоційні історії — сторітелінг.
3. Відео з'являються в блоці **«Черга»** й обробляються по одному: завантаження, транскрипція, пошук моментів Gemini. Вкладку можна закрити — черга працює, поки запущена студія, і продовжиться після перезапуску. Невдалий пункт можна повторити, завершені — прибрати кнопкою «Прибрати завершені».
4. Готові відео лежать у **«Твої відео»** — клік по картці відкриває монтажний стіл: плеєр, «Беру / Не беру», межі кліпу, допис і хештеги, завантаження MP4, SRT.

### Вертикальні кліпи 9:16 із субтитрами

У монтажному столі, вкладка **«Скачати»**:

- **Кадр 9:16**: «Авто» (одна людина: кадр слідкує за обличчям; двоє: екран ділиться навпіл; облич немає: весь кадр на розмитому тлі), «Весь кадр» або «Стрім: вебка + гра».
- **Стрім: вебка + гра** (для записів стрімів Twitch / YouTube): студія сама знаходить рамку вебки (один раз на відео), її можна посунути в «Рамки на кадрі». Три розкладки: вебка зверху і гра знизу, вебка + вся гра (смужку з вебкою відрізано, тож стрімера в грі не видно), гра на весь екран із віконцем вебки (його можна розтягнути аж на всю ширину й поставити будь-де). Вебка всередині гри розмивається, щоб обличчя не було двічі. Усе робиться прямо на телефоні, як у CapCut: клікни по вебці чи грі, з'явиться рамка з ручками; тягни кут, щоб збільшити, тягни всередині, щоб посунути, межу між ними теж можна тягнути, коліщатко наближує. Оформлення: заокруглені кути, кольорова рамка, лінія між вебкою й грою, нік стрімера в одному з п'яти стилів (плашка Twitch, неон, біла пігулка, жирний з тінню, стрічка); нік можна перетягнути будь-куди. Усе це одне на відео, або «Лише для цього кліпу». Якщо на відео знайдено вебку, «Стрім» вмикається сам, і з'являється вікно «Схоже, це запис стріму» з кадром і знайденою вебкою: можна продовжити, поправити рамку або сказати, що це не стрім. Коли стрімер посеред кліпу на весь екран або вебка переїхала, кліп сам перемикає картинку. Для стрімів ШІ отримує підказки: де стрімер різко голоснішав (крик, сміх) і де вибухнув чат (якщо в Twitch / YouTube є запис чату).
- **Субтитри**: Хайлайт, Караоке, Одне слово, Блок, Чорне золото, Мінімал або без субтитрів. Розмір, висота, колір виділення й тексту, прямі або закруглені плашки, чорне чи біле обведення. Заголовок зверху: свій текст, 4 варіанти вигляду, розмір, кути плашки, обведення, на перші 3 секунди або на весь кліп.
- **Текст субтитрів**: натисніть слово, щоб виправити помилку Whisper, прибрати слово або виділити його кольором.
- Попередній вигляд у маленькому «телефоні» показує кадр і субтитри разом із плеєром.
- Кнопки: «Вертикальний із субтитрами», «Вертикальний без субтитрів», **«Чистий кліп 16:9» (як і раніше, для монтажу)**, SRT. ZIP вертикальних для всіх кліпів «Беру».

Налаштування запам'ятовуються для кожного кліпу, а останні вибрані стають шаблоном для нових. Готовий файл: 1080×1920, 30 кадрів/с, H.264 (на відеокарті NVENC, якщо є). Обличчя шукає OpenCV (модель YuNet лежить у `assets/models`), шрифти з українськими літерами лежать у `frontend/fonts`.

Усі попередні відео зберігаються в **«Твої відео»** — клік відкриває результати без повторного аналізу.

### ⚙ Налаштування

Кнопка **«⚙ Налаштування»** вгорі. Зміни зберігаються одразу у файл `user_settings.json` (поверх `config.yaml`, у git не потрапляє). «Повернути все як було спочатку» скидає їх.

- **Кліпи**: найкоротший і найдовший кліп (секунд), скільки секунд можуть перетинатися два кліпи, скільки кліпів і що шукати для нових відео за замовчуванням.
- **Розпізнавання й ШІ**: якість Whisper (модель), мова відео, ключ Gemini (зберігається тільки в `.env` на цьому комп'ютері), «Другий прохід» — ШІ порівнює всі знайдені кліпи й уточнює оцінки (точніше, але на один запит більше).
- **Місце на диску**: скільки займає студія і що саме.
  - «Сміття» — недокачані файли, тимчасовий звук, залишки видалених відео. Прибирати безпечно.
  - «Готові файли кліпів» — нарізані 16:9 і вертикальні файли (усі або старші за 7 / 30 / 90 днів). Кліпи, позначки й налаштування лишаються, файл зробиться знову при «Скачати».
  - Автоприбирання при запуску студії: вимкнено за замовчуванням, можна ввімкнути на 7–60 днів.
  - «Відео за розміром» — найбільші джерела; видалення джерела видаляє і сам проєкт.

### Налаштування у файлі (`config.yaml`)

| Параметр | Що робить | Зараз |
|---|---|---|
| `clips.default_min_len` / `default_max_len` | Межі тривалості кліпу, сек | `15` / `60` |
| `whisper.model` | Модель розпізнавання (`small` — баланс; `medium` / `large-v3` — точніше, але повільніше й потребує більше VRAM) | `small` |
| `whisper.language` | Мова (`uk`, `en`, `auto`) | `uk` |
| `whisper.device` | `auto` / `cuda` / `cpu` | `auto` |
| `gemini.candidate_models` | Моделі Gemini у порядку спроб | 4 моделі |

Після зміни `config.yaml` перезапустіть студію. Те, що змінено в «⚙ Налаштування», має пріоритет над `config.yaml`.

## Якщо Gemini перевантажений

Студія перебирає всі моделі зі списку, робить до 3 проходів з паузами (5 с і 20 с). Якщо жодна не відповіла, з'явиться повідомлення:

> Google Gemini зараз перевантажений і не відповідає. Транскрипцію збережено, спробуйте ще раз через кілька хвилин.

Натисніть **«🔄 Спробувати ще раз»** — у блоці прогресу або в картці невдалого проєкту з історії. Транскрипція вже в кеші, тому повтор займе лише час відповіді Gemini.

## Як перевірити, що працює відеокарта

У консолі студії (або у `shorts_automator.log`) під час першого аналізу має бути:

```
Whisper device auto-detect → using CUDA
Initializing Faster-Whisper (CTranslate2): model='small' device=cuda compute_type=float16
```

і **не** має бути рядків `falling back to CPU`. Орієнтир: 4 хвилини аудіо на RTX 4050 розпізнаються приблизно за 20 секунд.

## Тести

```bash
.venv\Scripts\python.exe -m pytest tests -q
```

Тести використовують окрему тимчасову базу, папки й лог — ваші проєкти та `shorts_automator.log` вони не чіпають.

Тести сайту в браузері (`tests/e2e`) самі відкривають студію в Chromium і клікають: тема на головній, монтажний стіл, «Беру / Не беру», плеєр, клік по слову, межі кліпу, допис, завантаження MP4, SRT і ZIP. Один раз встановіть для них браузер:

```bash
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m playwright install chromium
```

Без Playwright ці тести просто пропускаються. Запустити лише їх: `.venv\Scripts\python.exe -m pytest tests/e2e -q`.

## Типові проблеми

| Симптом | Що робити |
|---|---|
| YouTube не завантажується / `Sign in to confirm` / зникли формати | Оновіть yt-dlp: `.venv\Scripts\python.exe -m pip install -U yt-dlp`. YouTube дедалі частіше вимагає JavaScript-рушій: встановіть [deno](https://deno.com) (`winget install DenoLand.Deno`) — yt-dlp підхопить його автоматично. |
| `cublas64_12.dll is not found` або Whisper повільний і в лозі `falling back to CPU` | Перевірте, що встановлені `nvidia-cublas-cu12` і `nvidia-cudnn-cu12` (`pip install -r requirements.txt`) і є свіжий драйвер NVIDIA (`nvidia-smi`). Студія сама додає їх папки `.venv\Lib\site-packages\nvidia\*\bin` до пошуку DLL. |
| `CUDA out of memory` | Закрийте ігри / інші GPU-програми або поставте менший `whisper.model`. |
| `GEMINI_API_KEY не знайдено` | Вставте ключ у «⚙ Налаштування» → «Розпізнавання й ШІ» або перевірте файл `.env` у корені проєкту. |
| Після оновлення коду кнопки не працюють або `Not Found` | Закрийте вікно студії, запустіть її знову й оновіть сторінку з `Ctrl+F5` — браузер міг тримати старі файли. |
| У консолі `_ProactorBasePipeTransport._call_connection_lost` | Нешкідливо: Windows так повідомляє, що браузер закрив вкладку або оновив сторінку. |
| `ffprobe` / `ffmpeg` не знайдено | Встановіть ffmpeg і перезапустіть студію. |

## Для розробника

- `run_studio.py` → FastAPI (`backend/server.py`) + фронтенд `frontend/`.
- `backend/job_runner.py` — фонові задачі аналізу й SSE-прогрес; `backend/queue_runner.py` — черга (по одному відео); `backend/storage.py` — місце на диску й прибирання; `backend/db.py` — SQLite (`studio_data.db`).
- `config_loader.py` — `config.yaml` + `user_settings.json`; `vertical_render.py` — вертикальні 9:16; `streamer.py` — режим стрімера (рамка вебки, розкладки); `clip_refiner.py` — детерміноване доведення кліпів після ШІ (межі, перекриття).
- `transcription.py` — Faster-Whisper + кеш; `ai_selector.py` — промпт Gemini, повтори, валідація кліпів; `subtitles_generator.py` — SRT.
- CLI без веб-інтерфейсу: `.venv\Scripts\python.exe repurpose_agent.py "відео.mp4" -c 10 -f viral` (`-f`: `viral` / `advice` / `story`).
- Архітектурні нотатки: [`.antigravity/`](.antigravity/ARCHITECTURE.md).
